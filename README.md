# analitik
Скилл Codex «Финансовый аналитик» для всех, кто работает с данными, таблицами и Excel: своды выгрузок, факт и план, маржа, «что если» и прогноз, склад (покрытие, ABC/XYZ, неликвид), реклама, проверка чужих таблиц и финмоделей, накладные в 1С, сверка двух источников, подозрительные платежи. Одна методика: сначала описание файлов и «да», пять частей запроса, три роли — строитель, проверка расчёта, адвокат дьявола. Заменяет скиллы `buhgalter` и `finansist`.

Установка — [INSTALL.md в prompt-helper](https://github.com/Automall-Training/prompt-helper/blob/main/INSTALL.md).
